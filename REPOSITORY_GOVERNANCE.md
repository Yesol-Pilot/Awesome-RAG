## Purpose and boundaries

This repository is a personal retrieval-augmented generation reference index. It is not an approved knowledge system, vector store, retrieval policy, evaluation standard, or production dependency set.

- Entries retain source, version, date, license, maintenance state, supported data types, and major privacy or infrastructure assumptions where practical.
- RAG quality claims require fixed corpora, chunking, index, query set, retrieval metric, generation model, citation test, and date.
- Documents, embeddings, indexes, logs, and evaluation sets may contain personal, copyrighted, confidential, or regulated data and require independent rights and privacy review.
- Connectors, loaders, plugins, notebooks, containers, and agents require secret, supply-chain, prompt-injection, and data-exfiltration review before use.

## Required controls

- [ ] Run full-history secret, license, dead-link, dataset-rights, dependency, malware, and provenance audits.
- [ ] Mark stale, abandoned, unsafe, or license-unclear resources.
- [ ] Separate descriptive references from executable connectors and downloadable corpora or indexes.
- [ ] Require retrieval, citation, privacy, access-control, deletion, and rollback validation before company adoption.

## Exit criteria

The repository is `REFERENCE_COMPLIANT` only when source and version lineage are visible, data and connector risks are disclosed, stale material is marked, and ownership remains intentionally personal.

The presence of this file alone is not production or factuality approval.
